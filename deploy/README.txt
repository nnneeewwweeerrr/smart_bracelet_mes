============================================
  智能手环MES系统 - 服务器部署包
============================================

部署步骤：
1. 将 server 文件夹整体上传到阿里云服务器 /opt/mes-package/
   (可用scp或WinSCP等工具)

2. SSH登录服务器，执行以下命令：

   # 移动文件到目标目录
   mkdir -p /opt/mes
   cp -r /opt/mes-package/server/* /opt/mes/

   # 赋予执行权限并运行部署脚本
   cd /opt/mes
   chmod +x deploy.sh
   sudo ./deploy.sh

3. 等待脚本执行完成（约5-10分钟）

4. 浏览器访问 http://47.105.66.12 验证

5. 小程序在微信开发者工具中打开 mini-app 目录
   详情中勾选「不校验合法域名」
