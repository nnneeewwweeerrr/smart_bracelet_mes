# 智能手环MES系统 - 用户操作手册

## 1. 系统概述

### 1.1 系统简介

智能手环MES系统是一款面向智能手环制造企业的生产制造执行系统，包含网页管理端和小程序现场端，覆盖订单、采购、仓储、生产、质检、异常全流程数字化管理。

### 1.2 适用角色

| 角色 | 职责 |
|------|------|
| 管理员 | 系统管理、用户权限管理 |
| 订单专员 | 订单创建、审批、跟踪 |
| 采购专员 | 采购计划、供应商管理 |
| 仓库管理员 | 入库、出库、库存管理 |
| 生产主管 | 生产计划、工单管理 |
| 质检人员 | 质检任务、质检录入 |
| 一线工人 | 生产报工、异常上报 |

## 2. 网页管理端操作指南

### 2.1 登录系统

1. 打开浏览器，访问系统地址：`http://your-domain.com`
2. 输入用户名和密码
3. 点击【登录】按钮

### 2.2 首页看板

登录后默认进入首页看板，展示：

- 订单完成率统计
- 生产进度概览
- 库存预警信息
- 今日待办任务

### 2.3 订单管理

#### 2.3.1 创建订单

1. 点击左侧菜单【订单管理】
2. 点击【新建订单】按钮
3. 填写订单信息：客户、产品、数量、单价等
4. 点击【保存】按钮

#### 2.3.2 订单审批

1. 在订单列表中找到待审批订单
2. 点击订单编号进入详情页
3. 点击【审批】按钮
4. 选择审批结果并填写备注
5. 点击【确认】按钮

#### 2.3.3 订单跟踪

1. 在订单列表中选择目标订单
2. 点击【进度跟踪】按钮
3. 查看订单的生产进度、质检结果等信息

### 2.4 采购管理

#### 2.4.1 创建采购订单

1. 点击左侧菜单【采购管理】
2. 点击【新建采购单】按钮
3. 填写采购信息：供应商、物料、数量等
4. 点击【保存】按钮

#### 2.4.2 供应商管理

1. 点击左侧菜单【采购管理】->【供应商管理】
2. 点击【新增供应商】按钮
3. 填写供应商信息：名称、联系人、电话、地址等
4. 点击【保存】按钮

### 2.5 仓储管理

#### 2.5.1 入库操作

1. 点击左侧菜单【仓储管理】->【入库管理】
2. 点击【新建入库单】按钮
3. 填写入库信息：物料、仓库、数量、来源等
4. 点击【保存】按钮

#### 2.5.2 出库操作

1. 点击左侧菜单【仓储管理】->【出库管理】
2. 点击【新建出库单】按钮
3. 填写出库信息：物料、仓库、数量、目标等
4. 点击【保存】按钮

#### 2.5.3 库存查询

1. 点击左侧菜单【仓储管理】->【库存查询】
2. 输入查询条件：物料名称、仓库等
3. 点击【查询】按钮
4. 查看库存列表

### 2.6 生产管理

#### 2.6.1 创建生产计划

1. 点击左侧菜单【生产管理】->【生产计划】
2. 点击【新建计划】按钮
3. 填写计划信息：关联订单、产品、产量、时间等
4. 点击【保存】按钮

#### 2.6.2 创建工单

1. 点击左侧菜单【生产管理】->【工单管理】
2. 点击【新建工单】按钮
3. 填写工单信息：关联计划、工序、数量等
4. 点击【保存】按钮

#### 2.6.3 生产进度

1. 点击左侧菜单【生产管理】->【生产进度】
2. 选择目标生产计划
3. 查看各工序的完成情况

### 2.7 质量管理

#### 2.7.1 创建质检任务

1. 点击左侧菜单【质量管理】->【质检任务】
2. 点击【新建任务】按钮
3. 填写任务信息：任务类型、关联单据、检验员等
4. 点击【保存】按钮

#### 2.7.2 提交质检结果

1. 在质检任务列表中找到待处理任务
2. 点击【处理】按钮
3. 填写各检验项目的实际值和结果
4. 点击【提交】按钮

### 2.8 设备管理

#### 2.8.1 设备台账

1. 点击左侧菜单【设备管理】->【设备台账】
2. 查看设备列表信息

#### 2.8.2 添加设备

1. 点击【新增设备】按钮
2. 填写设备信息：编码、名称、类型、位置等
3. 点击【保存】按钮

### 2.9 系统管理

#### 2.9.1 用户管理

1. 点击左侧菜单【系统管理】->【用户管理】
2. 点击【新增用户】按钮
3. 填写用户信息：用户名、密码、真实姓名、角色等
4. 点击【保存】按钮

#### 2.9.2 角色管理

1. 点击左侧菜单【系统管理】->【角色管理】
2. 点击【新增角色】按钮
3. 填写角色名称和编码
4. 配置角色权限
5. 点击【保存】按钮

## 3. 小程序端操作指南

### 3.1 登录小程序

1. 打开微信，搜索小程序【智能手环MES】
2. 使用工号和密码登录

### 3.2 工作台

登录后默认进入工作台，展示：

- 今日任务列表
- 快捷操作入口

### 3.3 扫码功能

#### 3.3.1 扫码入库

1. 点击底部导航【扫码】
2. 选择【扫码入库】
3. 扫描物料条码
4. 确认入库信息，点击【确认】

#### 3.3.2 扫码出库

1. 点击底部导航【扫码】
2. 选择【扫码出库】
3. 扫描物料条码
4. 确认出库信息，点击【确认】

#### 3.3.3 扫码报工

1. 点击底部导航【扫码】
2. 选择【扫码报工】
3. 扫描工单条码
4. 填写报工数量，点击【确认】

### 3.4 生产报工

1. 点击底部导航【工作台】
2. 找到待报工的工单
3. 点击【报工】按钮
4. 填写合格数量和不合格数量
5. 点击【提交】按钮

### 3.5 质检录入

1. 在工作台找到待处理的质检任务
2. 点击任务进入详情页
3. 填写各检验项目的结果
4. 点击【提交】按钮

### 3.6 异常上报

1. 点击底部导航【工作台】
2. 点击【异常上报】按钮
3. 选择异常类型
4. 填写异常描述
5. 点击【提交】按钮

### 3.7 个人中心

1. 点击底部导航【我的】
2. 查看个人信息
3. 修改密码
4. 查看操作记录

## 4. 常见问题

### 4.1 忘记密码

联系管理员重置密码

### 4.2 订单无法审批

检查是否有审批权限

### 4.3 库存不足

联系采购专员进行采购

### 4.4 设备故障

在设备管理中上报设备故障，联系维修人员处理
