# AI生产问答助手 - 答辩演示操作说明

> 覆盖「网页对话 + 图谱可视化 + 小程序扫码语音提问」三大演示场景

---

## 一、环境准备

### 1.1 启动后端服务

```bash
cd backend
mvn spring-boot:run
```
- 服务地址：http://localhost:8080
- 启动后自动初始化：AI对话表、5份SOP知识文档、45个知识图谱节点

### 1.2 启动Web管理端

```bash
cd web-admin
npm install    # 首次运行
npm run dev
```
- 访问地址：http://localhost:5180（或终端提示的端口）
- 默认账号：`admin` / `123456`

### 1.3 启动小程序端

```bash
cd mini-app
npm install    # 首次运行
npm run dev
```
- 用 HBuilderX 打开 mini-app 目录，运行到浏览器/模拟器/真机
- 小程序默认账号：`worker001` / `123456`

## 二、演示场景一：网页AI对话

### 2.1 基础对话演示

1. 打开 http://localhost:5180 ，使用 `admin/123456` 登录
2. 观察页面右下角有**蓝色渐变AI助手悬浮按钮**
3. 点击按钮展开对话窗口
4. 在输入框输入问题，点击发送或按回车

**推荐演示问题：**

| 问题示例 | 演示亮点 |
|----------|----------|
| `SMT贴片工艺的回流焊温度是多少？` | RAG检索SOP文档，回答带引用来源 |
| `屏幕贴合出现气泡应如何处理？` | 知识图谱不良分析，给出原因和解决方案 |
| `当前库存情况如何？` | 业务数据意图识别，实时查询库存数据 |
| `当前产品的良率如何？` | 良率场景识别，返回质检统计 |
| `当前工单进度怎么样？` | 工单进度场景，返回工单状态分布 |

### 2.2 引用来源展示

- AI回答下方会显示**引用来源**标签
- 点击来源标签可展开查看知识片段内容
- 来源类型标注为「知识图谱」或「文档」

### 2.3 业务页面「问AI」按钮

1. **工单管理页**（左侧菜单 → 生产管理 → 生产工单）
   - 选中一行工单，点击右上角「问AI」按钮
   - AI助手自动展开并带入工单上下文提问

2. **工艺配置页**（左侧菜单 → 生产管理 → 工艺配置）
   - 点击右上角「问AI」按钮
   - 自动询问工艺SOP操作规范

3. **异常处理页**（左侧菜单 → 质量管理 → 异常处理）
   - 点击右上角「问AI」按钮
   - 自动询问异常处理方案

### 2.4 对话反馈

- 每条AI回答下方有「有用」/「无用」反馈按钮
- 点击后系统记录反馈，用于后续优化

## 三、演示场景二：知识图谱可视化

### 3.1 打开知识图谱页面

1. 左侧菜单 → **AI助手** → **知识图谱**
2. 页面加载后显示ECharts力导向图，包含45个节点

### 3.2 图谱交互演示

1. **节点着色**：不同类型节点用不同颜色（工序=蓝、不良=红、原因=橙、方案=绿、物料=紫、设备=青）
2. **点击节点**：右侧面板显示节点详情（名称、类型、描述、关联关系）
3. **搜索节点**：顶部搜索框输入关键词（如"虚焊"），高亮匹配节点
4. **缩放拖拽**：鼠标滚轮缩放，拖拽节点调整布局

### 3.3 不良分析演示

1. 在搜索框输入不良名称（如"偏移"、"锡珠"、"气泡"）
2. 点击搜索结果，右侧面板展示：
   - 不良现象描述
   - 可能原因列表（按置信度排序）
   - 对应解决方案

## 四、演示场景三：小程序扫码语音提问

### 4.1 进入AI助手

1. 打开小程序，登录（`worker001/123456`）
2. 在**工作台**页面，点击醒目的「AI助手」卡片入口
3. 进入AI对话主页面（深色科技风格）

### 4.2 文字提问演示

1. 底部输入框输入问题，点击「发送」
2. 推荐点击顶部快捷标签快速提问：
   - `焊接温度` → 智能手环焊接工序的推荐温度
   - `屏幕气泡` → 屏幕贴合气泡处理方案
   - `报工操作` → 生产报工操作指引
   - `防水测试` → 防水测试标准与步骤

### 4.3 扫码联动演示

1. 点击右上角「扫」按钮
2. 扫描工单/工位/SN码/物料码
3. 系统自动识别码类型并生成问题：
   - 工单号（WO开头）→ "工单WOxxxx的生产进度如何？"
   - SN码（SN开头）→ "SN码SNxxxx的生产追溯信息？"
   - 物料批次 → "物料xxxx的库存信息？"
4. 自动发送问题并返回AI回答

### 4.4 语音输入演示

1. 长按底部「🎤」按钮开始录音
2. 页面显示录音波纹动效
3. 松开按钮，系统识别语音内容
4. 识别结果自动填入输入框，点击发送

### 4.5 语音播报演示

1. AI回答后，回答气泡下方有「▶ 播报」按钮
2. 点击按钮，使用TTS语音播报回答内容
3. 播报中按钮变为「⏹ 停止」，可随时停止

### 4.6 快捷操作跳转

- AI回答中若包含"异常上报""报工""库存查询"等关键词
- 回答下方自动出现快捷跳转按钮
- 点击可直接跳转到对应业务页面

## 七、常见问题

**Q: AI回答提示"暂无对应规范"？**
A: 说明知识库中未匹配到相关内容，可尝试换一种提问方式，或在知识库管理中上传相关文档。

**Q: 小程序语音识别失败？**
A: 语音识别需要真机环境或模拟器支持，浏览器预览可能不支持录音。文字输入方式始终可用。

**Q: 知识图谱页面空白？**
A: 等待页面加载完成，ECharts力导向图需要约2秒布局计算。如仍空白，刷新页面。

**Q: 业务数据问答返回"general"场景？**
A: 确保问题中包含关键词：库存、产量、良率/合格率、工单进度/生产进度。
