# 智能手环MES系统 - 数据库设计说明书

## 1. 数据库概述

### 1.1 数据库选型

采用MySQL 8.0+作为数据库管理系统，支持事务、索引优化、主从复制等特性。

### 1.2 数据库命名规范

- 数据库名：`smart_bracelet_mes`
- 表名：小写英文，下划线分隔，如 `sys_user`
- 字段名：小写英文，下划线分隔，如 `user_name`
- 主键：统一命名为 `id`，类型为 `BIGINT`

### 1.3 数据类型规范

| 数据类型 | 使用场景 |
|----------|----------|
| BIGINT | 主键ID |
| VARCHAR | 字符串，长度根据实际需求 |
| INT | 整数，如数量、状态码 |
| DECIMAL | 金额、精度要求高的数值 |
| DATETIME | 时间戳，格式 `YYYY-MM-DD HH:MM:SS` |
| TEXT | 长文本内容 |
| BOOLEAN | 布尔值 |

## 3. 数据库关系图

```
sys_user ──┬── sys_role ── sys_permission
           └── sys_dict

order_customer ── production_plan ── work_order ──┬── production_report
                                                   └── exception_record
                                                   └── quality_task ── quality_result

purchase_order ──┬── supplier_info
                 └── material_info ── stock_info ──┬── stock_in
                                                   └── stock_out

warehouse_info ─── stock_info

product_info ──┬── process_info
               └── order_customer
               └── work_order

equipment_info
```

## 4. 索引设计

| 表名 | 索引字段 | 索引类型 |
|------|----------|----------|
| sys_user | user_name | UNIQUE |

| purchase_order | purchase_no | UNIQUE |
