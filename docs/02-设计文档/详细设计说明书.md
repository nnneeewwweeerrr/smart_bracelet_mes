# 智能手环MES系统 - 详细设计说明书

## 1. 系统架构设计

### 1.1 总体架构

本系统采用前后端分离架构，分为三层：

- **表现层**: Vue3网页管理端 + UniApp小程序端
- **服务层**: SpringBoot后端服务
- **数据层**: MySQL数据库

### 1.2 技术选型

| 分类 | 技术 | 版本 |
|------|------|------|
| 后端框架 | SpringBoot | 2.7.x |
| ORM框架 | MyBatis | 2.2.x |
| 数据库 | MySQL | 8.0+ |
| 前端框架 | Vue | 3.x |
| 前端构建 | Vite | 5.x |
| UI组件 | Element Plus | 2.x |
| 小程序框架 | UniApp | 3.x |

## 2. 后端详细设计

### 2.1 目录结构

```
backend/src/main/java/com/mes/
├── controller/     # 控制层
├── service/        # 业务层接口
│   └── impl/       # 业务层实现类
├── mapper/         # 数据访问层
├── entity/         # 数据库实体类
├── dto/            # 请求入参对象
├── vo/             # 返回视图对象
├── config/         # 配置类
├── common/         # 通用类
└── utils/          # 工具类
```

### 2.2 Controller层设计

| 控制器 | 路径前缀 | 功能说明 |
|--------|----------|----------|
| OrderController | /api/order | 订单管理 |
| PurchaseController | /api/purchase | 采购管理 |
| StockController | /api/stock | 仓储管理 |
| ProductionController | /api/production | 生产管理 |
| QualityController | /api/quality | 质量管理 |
| EquipmentController | /api/equipment | 设备管理 |
| SystemController | /api/system | 系统管理 |

### 2.3 Service层设计

| 服务接口 | 实现类 | 功能说明 |
|----------|--------|----------|
| OrderService | OrderServiceImpl | 订单业务逻辑 |
| PurchaseService | PurchaseServiceImpl | 采购业务逻辑 |
| StockService | StockServiceImpl | 仓储业务逻辑 |
| ProductionService | ProductionServiceImpl | 生产业务逻辑 |
| QualityService | QualityServiceImpl | 质量业务逻辑 |
| EquipmentService | EquipmentServiceImpl | 设备业务逻辑 |
| SystemService | SystemServiceImpl | 系统业务逻辑 |

### 2.4 通用类设计

| 类名 | 功能说明 |
|------|----------|
| Result | 统一返回结果封装 |
| ResultCode | 返回码枚举 |
| BusinessException | 业务异常类 |
| GlobalExceptionHandler | 全局异常处理 |

## 4. 安全设计

### 4.1 用户认证

- JWT Token认证机制
- Token有效期：2小时
- 支持刷新Token

### 4.2 权限控制

- 基于角色的权限控制(RBAC)
- 菜单级权限控制
- 按钮级权限控制

### 4.3 数据安全

- 密码使用BCrypt加密存储
- 接口请求参数校验
- SQL注入防护
