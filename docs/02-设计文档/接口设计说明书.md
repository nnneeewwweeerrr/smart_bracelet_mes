# 智能手环MES系统 - 接口设计说明书

## 1. 接口概述

### 1.1 接口规范

- 接口协议：HTTP/HTTPS
- 请求方式：GET/POST/PUT/DELETE
- 数据格式：JSON
- 字符编码：UTF-8
- 统一前缀：`/api`

### 1.2 响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "timestamp": 1678901234567
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | INT | 返回码，200表示成功 |
| message | STRING | 返回消息 |
| data | OBJECT/ARRAY | 返回数据 |
| timestamp | LONG | 时间戳 |

### 1.3 错误码定义

| 错误码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未登录或Token过期 |
| 403 | 无权限访问 |
| 500 | 服务器内部错误 |

## 2. 系统管理接口

### 2.1 用户登录

- **路径**: `POST /api/system/login`
- **请求体**:
```json
{
  "userName": "admin",
  "password": "123456"
}
```
- **响应**:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "xxx",
    "user": {
      "id": 1,
      "userName": "admin",
      "realName": "管理员",
      "roleId": 1
    }
  }
}
```

### 2.2 获取用户列表

- **路径**: `GET /api/system/user/list`
- **请求参数**:
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | INT | 是 | 页码 |
| size | INT | 是 | 每页数量 |
| userName | STRING | 否 | 用户名模糊查询 |

### 2.3 添加用户

- **路径**: `POST /api/system/user`
- **请求体**:
```json
{
  "userName": "test",
  "password": "123456",
  "realName": "测试用户",
  "phone": "13800138000",
  "email": "test@example.com",
  "roleId": 2
}
```

### 2.4 更新用户

- **路径**: `PUT /api/system/user/{id}`

### 2.5 删除用户

- **路径**: `DELETE /api/system/user/{id}`

### 2.6 获取角色列表

- **路径**: `GET /api/system/role/list`

### 2.7 获取数据字典

- **路径**: `GET /api/system/dict/{dictType}`

## 3. 订单管理接口

### 3.1 获取订单列表

- **路径**: `GET /api/order/list`
- **请求参数**:
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | INT | 是 | 页码 |
| size | INT | 是 | 每页数量 |
| orderNo | STRING | 否 | 订单号 |
| status | INT | 否 | 订单状态 |

### 3.2 创建订单

- **路径**: `POST /api/order`
- **请求体**:
```json
{
  "customerId": 1,
  "productId": 1,
  "quantity": 1000,
  "unitPrice": 199.00
}
```

### 3.3 获取订单详情

- **路径**: `GET /api/order/{id}`

### 3.4 审批订单

- **路径**: `PUT /api/order/{id}/approve`
- **请求体**:
```json
{
  "approveStatus": 1,
  "remark": "审批通过"
}
```

### 3.5 获取订单进度

- **路径**: `GET /api/order/{id}/progress`
