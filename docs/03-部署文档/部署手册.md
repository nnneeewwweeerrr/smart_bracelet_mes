# 智能手环MES系统 - 部署手册

## 1. 环境要求

### 1.1 硬件要求

| 配置项 | 最低配置 | 推荐配置 |
|--------|----------|----------|
| CPU | 4核 | 8核 |
| 内存 | 8GB | 16GB |
| 硬盘 | 100GB | 500GB |
| 网络 | 100Mbps | 1Gbps |

### 1.2 软件要求

| 软件 | 版本 | 说明 |
|------|------|------|
| JDK | 11 | 后端运行环境 |
| MySQL | 8.0+ | 数据库 |
| Node.js | 18+ | 前端构建环境 |
| Maven | 3.8+ | 后端构建工具 |

## 2. 数据库部署

### 2.1 创建数据库

```sql
CREATE DATABASE smart_bracelet_mes 
  CHARACTER SET utf8mb4 
  COLLATE utf8mb4_unicode_ci;
```

### 2.2 执行建表脚本

```bash
mysql -u root -p smart_bracelet_mes < sql/schema.sql
```

### 2.3 执行初始化数据

```bash
mysql -u root -p smart_bracelet_mes < sql/init_data.sql
```

### 2.4 创建数据库用户

```sql
CREATE USER 'mes_user'@'localhost' IDENTIFIED BY 'password';
GRANT ALL PRIVILEGES ON smart_bracelet_mes.* TO 'mes_user'@'localhost';
FLUSH PRIVILEGES;
```

## 3. 后端服务部署

### 3.1 配置文件修改

修改 `backend/src/main/resources/application.yml`：

```yaml
server:
  port: 8081

spring:
  datasource:
    url: jdbc:mysql://localhost:3306/smart_bracelet_mes?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
    username: mes_user
    password: password
```

### 3.2 打包构建

```bash
cd backend
mvn clean package -DskipTests
```

### 3.3 启动服务

#### 开发模式

```bash
mvn spring-boot:run
```

#### 生产模式

```bash
java -jar target/smart-bracelet-mes-1.0.0.jar
```

### 3.4 配置系统服务

创建 `/etc/systemd/system/mes-backend.service`：

```ini
[Unit]
Description=Smart Bracelet MES Backend Service
After=network.target mysql.service

[Service]
Type=simple
User=root
WorkingDirectory=/opt/mes/backend
ExecStart=/usr/bin/java -jar smart-bracelet-mes-1.0.0.jar
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
systemctl daemon-reload
systemctl start mes-backend
systemctl enable mes-backend
```

## 4. 前端管理端部署

### 4.1 修改配置

修改 `web-admin/src/utils/request.js` 中的API地址：

```javascript
baseURL: 'http://your-server-ip:8081/api'
```

### 4.2 构建项目

```bash
cd web-admin
npm install
npm run build
```

### 4.3 Nginx配置

创建 `/etc/nginx/conf.d/mes-web.conf`：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        root /opt/mes/web-admin/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://localhost:8081/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

## 5. 小程序端部署

### 5.1 构建微信小程序

npm install

## 6. 安全配置

### 6.1 防火墙配置

```bash
# 开放80端口（前端）
firewall-cmd --zone=public --add-port=80/tcp --permanent
# 开放8081端口（后端）
firewall-cmd --zone=public --add-port=8081/tcp --permanent
firewall-cmd --reload
```

### 6.2 HTTPS配置

使用Let's Encrypt配置HTTPS：

```bash
certbot --nginx -d your-domain.com
```

## 7. 数据备份

### 7.1 定时备份脚本

创建 `/opt/mes/backup.sh`：

```bash
#!/bin/bash
BACKUP_DIR="/opt/mes/backup"
DATE=$(date +%Y%m%d_%H%M%S)
MYSQL_USER="mes_user"
MYSQL_PASSWORD="password"
MYSQL_DATABASE="smart_bracelet_mes"

mkdir -p $BACKUP_DIR
mysqldump -u $MYSQL_USER -p$MYSQL_PASSWORD $MYSQL_DATABASE > $BACKUP_DIR/$MYSQL_DATABASE_$DATE.sql

find $BACKUP_DIR -name "*.sql" -mtime +7 -delete
```

### 7.2 设置定时任务

```bash
crontab -e
```

添加：

```
0 2 * * * /opt/mes/backup.sh
```

## 9. 常见问题

### 9.1 数据库连接失败

检查数据库服务是否启动：

```bash
systemctl status mysqld
```

### 9.2 后端服务启动失败

查看日志文件：

```bash
tail -f backend/logs/application.log
```

### 9.3 前端页面无法访问

检查Nginx配置和服务状态：

```bash
nginx -t
systemctl status nginx
```
