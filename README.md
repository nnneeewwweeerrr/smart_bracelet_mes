# 智能手环MES系统

> 智能手环生产制造执行系统(MES)，包含网页管理端与小程序现场端，覆盖订单、采购、仓储、生产、质检、异常全流程数字化管理

## 项目简介

本系统是一款面向智能手环制造企业的生产制造执行系统（MES），旨在实现生产全流程的数字化管理，提升生产效率和产品质量。

## 技术架构

- **后端**: SpringBoot 2.7.x + MyBatis + MySQL
- **前端管理端**: Vue3 + Vite + Element Plus
- **小程序端**: UniApp

## 功能模块

| 模块 | 说明 |
|------|------|
| 订单管理 | 客户订单的创建、审批、跟踪 |
| 采购管理 | 采购计划、采购订单、供应商管理 |
| 仓储管理 | 原材料入库、成品出库、库存盘点 |
| 生产管理 | 生产计划、工单管理、生产报工 |
| 质量管理 | 来料检验、过程检验、成品检验 |
| 设备管理 | 设备台账、维护保养、设备状态 |
| 系统管理 | 用户管理、角色权限、数据字典 |

## 项目结构

```
SmartBraceletMES/
├── backend/          # 后端SpringBoot项目
├── web-admin/        # 网页管理端Vue3项目
├── mini-app/         # 小程序端uni-app项目
├── docs/             # 项目全生命周期文档
└── sql/              # 数据库脚本
```

## 快速开始

### 后端启动

```bash
cd backend
mvn spring-boot:run
```

### 前端管理端启动

```bash
cd web-admin
npm install
npm run dev
```

### 小程序端启动

```bash
cd mini-app
npm install
npm run dev:h5
```
